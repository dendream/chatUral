# chatUral

Репозиторий проекта chatUral.

## Облачная среда

Требуемый режим доступа к сайтам по HTTP/HTTPS: `unrestricted`.
Он задаётся и сохраняется в сетевых настройках облачной среды.
Этот README документирует требование; файлы Git сами по себе не меняют
сетевую политику платформы.

Сохранение черновика и публикация среды — отдельные действия.
